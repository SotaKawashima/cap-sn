# 2026年9月23日：Twitch系列追加の検討と実行範囲の確定

## 1. Twitch系列を追加する案

指導教員との相談を受け、類似ネットワークによる傾向確認にSNAPの[Twitch Social Networks](https://snap.stanford.edu/data/twitch-social-networks.html)を追加する案を検討した。候補は`EN`、`ES`、`FR`、`RU`の4件である。これらは2018年5月に収集された言語別のTwitch配信者ネットワークで、ノードは配信者、無向辺は相互の友人関係を表す。

| 候補 | ノード数 | 辺数 |
| --- | ---: | ---: |
| EN | 7,126 | 35,324 |
| ES | 4,648 | 59,382 |
| FR | 6,549 | 112,666 |
| RU | 4,385 | 37,304 |

規模は今回使用するFacebook・Wiki系列におおむね近い。同一プラットフォーム・同一収集方法の4言語ネットワークなので、Twitch系列内で良好な候補領域の傾向が維持されるかを比較できる。追加する場合はFacebookの類似グラフとは扱わず、BA、Facebook、Wikiに続く**第4の実観測SNS系列**として位置付ける。SNAPに含まれる配信内容・言語・明示的表現ラベルなどのノード属性は今回の設計変数には使わず、既存の観測グラフと同じ方法でグラフごとの`comm.csv`を生成する必要がある。

## 2. 追加した場合の実験量

Twitch 4件にも既存案と同じく、3手法×6最適化シード×50評価×100反復の最適化、および無介入・単純最大化の固定比較を行う想定で比較した。

| 項目 | Twitchなし | Twitch 4件を追加 |
| --- | ---: | ---: |
| 追加グラフ数 | 7 | 11 |
| 最適化run | 126 | 198 |
| 固定条件run | 20 | 28 |
| 合計run | 146 | 226 |
| 最適化評価数 | 6,300 | 9,900 |
| 総シミュレーション反復 | 632,000 | 992,800 |

Twitch追加による増分は、最適化72 run、固定条件8 run、360,800反復であり、件数ベースでは約57%増える。第6段階の共用PC実績と追加FacebookグラフのMac上の短時間測定から、現在の直列runnerでは、Twitchなしで中心約7日（おおむね5--10日）、Twitchありで中心約8.5--9日（おおむね6--14日）と見積もった。グラフと介入点によってシミュレーション時間が大きく変わるため、これは確定値ではない。

## 3. 今回の判断

Twitch系列の追加は、別種のSNSでも目的関数面と良好領域の傾向を調べられるため、検証として有意義である。一方、CAS研究会までに入力準備、所要時間pilot、約100万反復の実行、分析まで完了させるには日程上の危険が大きい。

したがって、**今回の追加実験にはTwitchを含めない**。9月22日に確定したBA1000系列3件、Facebook系列3件、Wiki系列1件の計7追加グラフ、126最適化runと20固定条件runの計146 runで実行する。Twitch 4件は、CAS研究会後にネットワーク種別をさらに広げる場合の追加候補として保留する。今回のprotocol、runner、入力アーカイブは7グラフ版のまま変更しない。
