# 第10段階：情報拡散指標の再分析

## 1. この段階の目的

第10段階では，新目的関数 $J_{\mathrm{cum}}$ の改善時にどのような情報環境が生じていたかを再分析する．誤情報，訂正情報，観察情報，行動誘導情報の拡散量と，$J_{\mathrm{cum}}$ および補助指標 $J_{\mathrm{peak}}$ の関係を整理する．

中心的な問いは次の2点である．

1. 確実性・有効性および利己的行動の結果は，各情報の拡散指標とどのように関連するか．
2. 無介入，春学期代表条件，修正済み先行研究高説得力条件，第8段階で固定した最終候補の間で，情報環境はどのように異なるか．

情報拡散指標は，介入後に生じた過程を説明する**反応指標**として使用する．新たな最適化目的や候補選択基準にはしない．

## 2. この段階で行わないこと

- 第8段階で固定した候補の再選択やパラメータ調整は行わない．
- 情報拡散指標を目的関数とした最適化は行わない．
- 相関や条件間差だけから，特定の情報指標が利己的行動を因果的に減少させたとは断定しない．
- ネットワーク構造のどの要素が情報拡散を変えたかの分離実験は行わない．これは今後の課題とする．
- 全エージェントの詳細履歴は追加保存しない．

## 3. 用語

| 用語 | この段階での意味 |
| --- | --- |
| 情報拡散指標 | 情報種別ごとの共有数，閲覧数，初回アクセス数と，訂正情報／誤情報比率 |
| `num_fst_viewed` | 各情報オブジェクトへの初回アクセス数．ユニーク閲覧者数ではない |
| 反応指標 | 介入後に生じた情報環境を表す指標．独立に操作した原因ではない |
| 単純Spearman相関 | 2変数の順位の単調な関連を表す指標 |
| 偏Spearman相関 | 確実性と有効性の順位で説明できる部分を取り除いた残差間の相関 |
| paired比較 | 同一ネットワーク，同一seed，同一反復番号を対応させた条件間比較 |
| 階層paired bootstrap | seedブロックとその内部の反復を階層的に復元抽出し，paired差の95% CIを求める方法 |
| BH法 | 多数の相関を確認するときの偶然の検出増加を補助的に調整する方法 |

## 6. 情報拡散指標

反復 $m$ における情報種別 $q$ の全時刻の拡散数を $C_{m,q}$，エージェント数を $N$ とする．反復ごとの正規化拡散量は，

\[
D_{m,q}=\frac{C_{m,q}}{N}
\]

とし，実行単位では $M$ 反復の平均を用いる．これは全反復の合計値を $N\times M$ で除すことと等価である．実装上の列名では`*_per_agent_iteration`と表す．

訂正情報／誤情報比率は，

\[
R_m=\frac{C_{m,\mathrm{corrective}}}{C_{m,\mathrm{misinformation}}}
\]

で求める．誤情報側が0の場合は比率を欠損とし，欠損数，分子合計，分母合計を併記する．実行単位とbootstrapでは，個々の比率の単純平均ではなく**合計値の比**を使用する．

### 6.1 主指標

- 4種の情報それぞれの初回アクセス数．
- 訂正情報／誤情報の初回アクセス数比．

### 6.2 探索的指標

- 4種の情報それぞれの共有数と閲覧数．
- 訂正情報／誤情報の共有数比と閲覧数比．

初回アクセス数を「初回閲覧人数」や「ユニーク閲覧エージェント数」とは表現しない．

## 7. 分析方法

### 7.1 探索的相関

- 確実性・有効性と各情報指標のSpearman順位相関．
- 各情報指標と $J_{\mathrm{cum}}$，$J_{\mathrm{peak}}$ のSpearman順位相関．
- 確実性と有効性を統制した偏Spearman相関．
- 第2段階はランダムサーチを主分析，全手法を感度分析とする．
- p値とBH法によるq値は補助的に出力し，方向，大きさ，ネットワーク間の一致性を優先して解釈する．

### 7.2 固定条件のpaired比較

| 条件 | 意味 |
| --- | --- |
| `none` | 行動誘導情報を投入しない無介入条件 |
| `legacy_balance` | 春学期の代表条件（確実性0.8，有効性0.8） |
| `prior_high` | 修正済み先行研究高説得力CSV |
| `final_candidate` | 第8段階で固定したネットワーク別主候補 |

比較対は`legacy_balance vs none`，`prior_high vs none`，`final_candidate vs none`，`final_candidate vs legacy_balance`，`final_candidate vs prior_high`とする．各比較で，$J_{\mathrm{cum}}$，$J_{\mathrm{peak}}$，5個の主情報指標の差と95% CIを階層paired bootstrap 10,000回で求める．bootstrap seedは`94001`に固定する．

### 7.3 時系列

- 利己的行動は，条件別の累積実行者割合として描画する．
- 情報拡散は，情報種別ごとの1エージェント当たり累積初回アクセス数として描画する．
- 行動と情報は別図にし，2軸グラフは使用しない．
- 各時刻で5 seedの平均とt分布による95% CIを表示する．

## 8. 解釈の優先順位

1. 固定条件のpaired差と95% CI．
2. ネットワーク間での方向の一致・不一致．
3. 第2段階ランダムサーチの単純相関と偏相関．
4. 全最適化手法を含む感度分析．
5. 共有数・閲覧数の探索的結果．

単純相関が強くても，偏相関が弱まる場合は，「情報指標自体の独立した関係」ではなく，設計変数と連動した反応と解釈する．
